# Quantity total CLI

A small generic exercise for an empty project. No starter code is supplied.

Create a local command-line program that accepts one or more nonnegative decimal integers as arguments and prints their sum followed by a newline. Use an already available runtime; no third-party dependencies are needed.

## Required behavior

- R1: `2 3 0` prints `5` and exits with code 0.
- R2: `0` prints `0` and exits with code 0.
- R3: No arguments, a negative value, or a non-integer value prints a useful error to stderr, leaves stdout empty, and exits with code 2.

## Deliverables

The program, its run command and observed verification results. Work in a separate practice directory. This is a synthetic local exercise, not a task-specific solution or a requirement to use any particular language in other projects.
